# Timer

A minimal, dark, tactile timer app for iPhone. Five modes in one place — Clock, Countdown, Stopwatch, Interval, and Pomodoro — with no clutter, no subscriptions, and no account required.

---

## Features

**Clock**
- Live HH:MM:SS display, gyro-levelled
- Up to 5 alarms in a horizontal scrollable row
- Drag hour or minute digits up/down to set each alarm
- Toggle alarms on/off individually
- Tap + to add an alarm with a mitosis-style spring animation
- Hold an alarm card to delete it — glows red as confirmation, then flies off

**Countdown**
- Drag up/down to set time — slow drag for seconds, fast drag for minutes
- Two-finger drag jumps in 30-minute steps up to hours
- Tap to pause; tap again to resume
- 10-second warning with haptic and sound
- Glowing border ring tracks progress

**Stopwatch**
- Centisecond precision display
- Lap tracking with scrollable lap list

**Interval**
- Drag cards to set work and rest durations independently
- Configurable round count
- Phase transitions with sound and haptic cues

**Pomodoro**
- Drag to set focus, short break, and long break lengths
- Automatic long break after configurable session count
- Session progress dots

**Across all modes**
- Swipe left/right anywhere to switch modes
- Gyro level — digits counter-rotate to stay upright as your phone tilts (toggle in Settings)
- Customisable accent colour and background
- Fully customisable completion sound: melody pattern, pitch, and 10-second warning tone
- Haptics throughout, individually toggleable

## Settings

Swipe left past the Timer screen, or tap the dot to the left of the mode label when the nav pill is expanded.

| Setting | Options |
|---|---|
| Sound | On / Off |
| 10s Warning tone | Ping · Double · Bell |
| Melody pattern | Ascend · Cascade · Wave · Pulse |
| Pitch | −12 to +12 semitones |
| Haptics | On / Off |
| Gyro Level | On / Off |
| Timer colour | 6 accent presets |
| Background | 5 dark presets |
